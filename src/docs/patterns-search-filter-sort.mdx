# ค้นหา กรอง และเรียงข้อมูล

<Canvas of={DataTableStories.Default} />

## ค้นหา

- กล่องค้นหาอยู่ซ้ายสุดของ toolbar · placeholder บอกว่าค้นจากอะไร เช่น “ค้นหาเลขที่คำสั่งซื้อหรือชื่อลูกค้า”
- **Debounce 300ms** · มีปุ่ม ✕ ล้างคำค้น · ค้นหาจาก server เมื่อข้อมูลเกินหนึ่งหน้า
- รองรับการวางรหัสที่มีช่องว่างหรือตัวพิมพ์เล็กใหญ่ปนกัน (ทำ normalize ฝั่ง server)

## ตัวกรอง

- **แท็บ** สำหรับมิติหลักที่ใช้บ่อยที่สุด (เช่น สถานะ) พร้อมตัวนับ
- **Faceted filter** (ปุ่มเส้นประ) สำหรับมิติอื่น เลือกได้หลายค่า แสดงค่าที่เลือกบนปุ่ม
- เมื่อมีตัวกรองใด ๆ ให้แสดงปุ่ม **“ล้างตัวกรอง”** · ผลว่างจากตัวกรองใช้ `EmptyState kind="no-results"`
- กรองแล้วกลับไปหน้า 1 เสมอ

## เรียงข้อมูล

- กดหัวคอลัมน์ซ้ำเพื่อสลับลำดับ: **ข้อความ** เริ่มจาก ก→ฮ / A→Z, **ตัวเลขและวันที่** เริ่มจากมากไปน้อย (ใหม่สุดก่อน) · ไอคอนบอกสถานะ `<th>` มี `aria-sort` และปุ่มบอก screen reader ว่ากดแล้วจะเรียงแบบใด
- เรียงได้ทีละคอลัมน์ (ไม่ใช้ multi-sort ในหน้าจอปฏิบัติงาน)
- คอลัมน์ที่ไม่มีลำดับที่มีความหมาย (เช่น ช่องทาง) ไม่ต้องเปิดให้เรียง
